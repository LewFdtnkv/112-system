# Тренажёр операторов 112 и ДДС

Система для подготовки диспетчеров: от освоения интерфейса с пошаговым сопровождением до самостоятельной работы с обращениями и бригадами. Преподаватель составляет сценарии, назначает занятия и разбирает результаты учеников.

Возможности:

- Учебные карточки, справочник происшествий и подбор служб.
- Звонки через браузер или SIP-телефон, подготовка записей из текста.
- Автоматическое оценивание по правилам и с участием ИИ, пересмотр преподавателем.
- Генерация карточек, рекомендации ученикам и аналитика типичных ошибок. ИИ использует примеры и разборы из базы знаний.

**Развёртывание и тестовые данные описаны в [README бэкенда](112-backend/README.md#развёртывание).** Docker Compose запускается из `112-backend` и поднимает обе части системы. Параметры с пояснениями находятся в [шаблоне окружения](112-backend/.env.example); включение SIP-сервера описано в том же README. Для доступа по домену есть [настройка HTTPS через Nginx](112-backend/docs/HTTPS.md) с маршрутами API и браузерного телефона. [Демо-аккаунты и пароли](112-backend/docs/SEED.md#учётные-записи).

В репозитории два проекта:

- [112-backend](112-backend/README.md) — API, база данных и фоновые задачи. Python, FastAPI, PostgreSQL с pgvector, Ollama и Asterisk.
- [112-frontend](112-frontend/README.md) — рабочие места операторов и кабинеты пользователей. React, TypeScript, TanStack Query и Zustand. Здесь же инструкция по запуску интерфейса для разработки.
