# Администрирование и отчёты

## Пользователи

Аккаунт имеет одну роль: ученик, преподаватель или администратор. Для другой роли создаётся отдельный пользователь. Администратор не получает права преподавателя.

Администратор создаёт аккаунт, редактирует профиль и фото, сбрасывает пароль, отключает доступ и видит даты входа и изменений. После сброса пользователь обязан сменить временный пароль. Отключение отзывает сессии, но сохраняет занятия и результаты. Самоотключение и отключение последнего активного администратора запрещены.

Пользователь может менять собственный профиль, фото и пароль. Роль и системные даты таким образом не изменяются. Учебная работа доступна по назначению и владению, а не только по наличию роли.

## Группы и сообщения

Преподаватель управляет своими группами, составом, назначениями и сообщениями. Расформирование убирает текущий состав и закрывает группу для новых назначений, сохраняя историю. Назначенные занятия не удаляются.

Ученику доступны личные и групповые сообщения, отметки прочтения и рекомендации. Доступ к связанному занятию проверяется отдельно; наличие ссылки в сообщении не выдаёт новые права.

## Результаты и аналитика

Преподаватель видит собственные назначения, общую и недавнюю успеваемость, разбор карточек и пересмотр оценки. Аналитика типичных ошибок включает период, группу, роль оператора, рейтинг проблемных карточек и таблицу навыков.

Частичный ответ считается расхождением. Ожидающая или спорная проверка ИИ не доказывает ошибку. Работы с пересмотром только общего балла выделяются отдельно: такой пересмотр не описывает решение по каждому полю. При малом числе попыток выводится отметка о недостатке данных.

Экспорт XLSX/TXT содержит общий итог, покарточные ошибки, времена, нормативы, комментарии ИИ и преподавателя. Он использует сохранённые результаты без повторного вызова модели. Пользовательские строки не исполняются Excel как формулы. Групповой ИИ-разбор запускается отдельно по запросу преподавателя.

## Контроль фоновых задач

В «ИИ-задачах» администратор видит счётчики очереди, активных и завершённых задач. Детали содержат вход, результат, ошибки и контекст с возможностью скопировать JSON. Просмотр не перезапускает задачу. [Очередь и модели](AI.md).

Телефонные рабочие места настраиваются отдельно; SIP-пароль доступен администратору для копирования. [Настройка телефонии](TELEPHONY.md).

## Эксплуатация

```sh
docker compose ps
docker compose logs --tail=100 api worker speech-worker
```

Для звонков дополнительно проверяйте `asterisk` и `telephony-worker`. HTTP 5xx требует проверки журналов и доступности зависимостей; перезагрузка браузера не устраняет серверную причину.

Перед обновлением сохраняйте резервную копию PostgreSQL и тома `telephony_media`; список томов указан в `compose.yaml`. Проверьте восстановление на отдельном окружении. Удаление томов Compose удаляет данные и не является обычным перезапуском.

Секреты хранятся в окружении, не в Git. Первоначальный `admin/admin` требует смены пароля. Для тестирования используйте отдельную БД и [seed](SEED.md), а не рабочие учётные записи.
