# Проверка QA4

`group-model.json` — один реальный вызов Qwen3 4B Instruct-2507 Q4_K_M на
синтетической сводке: 16 карточек, 4 ошибки по статусам, 2 по назначению.
Векторный поиск выполнен локальной qwen3-embedding:0.6b на отдельной тестовой
PostgreSQL; данные учеников и рабочие оценки не использовались и не менялись.

Модель выбрала две отработки навыков (`focused`), 61,58 секунды. Промпт и
выбранные материалы сохранены полностью. Выбор соответствует входным ошибкам,
лишних навыков/фактов не добавлено; объяснения составлены из проверенных материалов.
Это проверка работоспособности, а не статистическая оценка качества рекомендаций.

`check_group_model.py` — повторяемый скрипт: из корня backend с отдельной
DATABASE_URL, доступным LLM_BASE_URL и PYTHONPATH корня проекта. Запускать только
на тестовой БД: наполняет методический корпус и его эмбеддинги, оценки не пишет.

Автоматические интеграционные проверки находятся в tests/test_qa4.py. Браузерные
проверки и снимки — в frontend e2e/qa4.spec.ts и docs/screenshots/qa4.
