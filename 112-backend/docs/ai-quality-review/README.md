# Проверка генерации и оценивания — 26.09.2026

Все вызовы выполнены локальной Qwen3 4B Instruct-2507 Q4_K_M через Ollama 0.34.2.
Рабочая БД читалась только для получения замороженных входов. Скрипт не захватывает
задачи, не публикует карточки и не меняет оценки. Старые тексты остаются в библиотеке.

## Подход

1. Повтор всех шести генераций с исходными фактами и seed, но текущим генератором.
2. Ручное чтение сообщений, а не только подсчёт `assisted`.
3. Повтор всех шести отказавших оцениваний со старым замороженным RAG-контекстом.
4. Контрольные примеры: допустимые короткие/ранние комментарии ДДС, неизвестное число,
   известный номер наряда, оправданная дополнительная служба; разные каналы и адреса генератора.

Исторические шесть оцениваний сохранили только общую ошибку. Ни таймаут, ни найденный
ниже OOM нельзя задним числом объявить доказанной причиной каждого из них.

## Что обнаружилось при испытаниях

- Первый вариант нового генератора подготовил все шесть сообщений без fallback.
  Консультация перестала добавлять адрес, возраст заявителя остался у заявителя,
  исчезли «У меня зовут» и «Я паникую». Критик один раз ошибочно пропустил в списке
  сохранённых фактов представление заявителя; повтор прошёл.
- При ручном чтении медицинского сообщения обнаружилась замена «не приходит в себя»
  на «не встаёт». Это разные признаки; критик пропустил подмену. Добавлена узкая
  проверка и явные сведения о сознании/дыхании в контексте писателя и критика.
- Даже при двух потоках длинная серия оцениваний исчерпала 4 GiB контейнера.
  Docker events подтвердил OOM. Перед падением движок сохранял очередной снимок
  промпта объёмом около 303 MiB; память росла до 3,96 GiB. Последующие мгновенные
  отказы — потеря соединения с перезапускающейся Ollama, не плохое решение ученика.
- У установленного llama-server кэш старых промптов по умолчанию имеет лимит 8192 MiB.
  `LLAMA_ARG_CACHE_RAM=0` отключает только этот дополнительный кэш. Логи подтвердили
  `prompt cache is disabled`, два потока и сохранение KV-контекста 4096 токенов.
  Лимит контейнера 4 GiB и память Docker Desktop не увеличивались.
- В рекомендации по описанию модель потребовала «точного воспроизведения» сообщения,
  хотя парафразы разрешены. Защита заменяет такой совет подготовленным текстом о
  сохранении смысла своими словами, сохраняя оригинал модели в диагностике.

## Ограничения

Известные ошибочные примеры использованы для настройки, поэтому это регрессии,
а не независимое измерение точности. В частности, пример «432» явно включён в промпт;
для дополнительного контроля используется другое число и допустимые ответы.
Нет утверждённой экспертной разметки заказчика. Небольшой прогон не доказывает
пригодность автономного оценивания для аттестации. Проверка преподавателем и
консервативное `uncertain` остаются необходимыми.

Свободный текст всё ещё может быть сухим или перечислительным. Узкие проверки
известных ошибок не заменяют общего понимания смысла и русского языка.

## Воспроизведение

`python -m scripts.replay_ai_jobs --purpose generation --output ./generation.json`
и аналогично `--purpose evaluation`. Необязательный повторяемый `--id` ограничивает
список задач. Отчёт содержит входные учебные данные, поэтому требует той же защиты,
что подробности ИИ-задач. Запускать внутри Docker с настроенным подключением к стенду.
