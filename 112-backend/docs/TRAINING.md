# Учебный процесс

## Роли и материалы

| Роль | Возможности |
| --- | --- |
| Ученик | Назначенные занятия, результаты, сообщения и личная практика по направлению |
| Преподаватель | Группы, материалы, назначения, аналитика, оценивание и примеры для ИИ |
| Администратор | Аккаунты, справочники, телефонные станции и диагностика задач |

Роль аккаунта неизменяема. Оператор 112 и оператор ДДС — режимы занятия, а не права пользователя.

**Карточка** — одна ситуация с условием и эталонным решением. **Сценарий** — набор карточек для выбранного оператора. **Занятие** — сценарий, назначенный группе или ученику с настройками обучения и времени.

Преподаватель создаёт карточки, собирает сценарий и назначает занятие. Для ДДС сначала выбирается профиль службы, затем подходящие ему карточки. Сохранённые версии сценария содержат снимки: последующие изменения библиотеки не переписывают прежние назначения. Использованная карточка защищена от редактирования; использованные сценарии архивируются с сохранением истории.

## Форматы и помощь

| Формат | Работа ученика |
| --- | --- |
| Освоение интерфейса | Действия с пошаговой подсветкой и объяснениями |
| Полная ситуация | Полная обработка с разрешённой помощью |
| Отработка навыка | Выбранные действия; остальное предзаполнено |
| Повторение | Повтор выбранных навыков на назначенном сценарии |
| Контроль | Полная ситуация без подсказок |

В полной ситуации и контроле навыки отдельно не выбираются. Подготовленные поля навыкового упражнения заблокированы и исключены из оценки. Несовместимые наборы навыков и карточек отклоняются при назначении.

Подсказки учитывают уже выполненные действия. Напоминание сообщает цель, объяснение помогает действовать, показ решения раскрывает значение или шаг. Глубину помощи задаёт преподаватель. В освоении точный ответ должен быть правильным до перехода; свободный ввод подтверждает ученик. Использованная помощь сохраняется, автоматического штрафа за неё нет.

## Доступность и время

| Настройка | Поведение |
| --- | --- |
| Дата начала | До неё начать нельзя; без неё занятие доступно сразу |
| Дата окончания | Общий конечный срок; без неё календарного ограничения нет |
| Лимит минут | Считается от личного начала, продолжает идти после выхода |
| Без лимита минут | Выход приостанавливает таймеры карточек, но не календарный срок |

Личный отсчёт запускается командой начала или открытием первой карточки, а не назначением. Завершение происходит по более раннему сроку: календарному окончанию либо личному лимиту. Повторное открытие не обнуляет время. Непройденные карточки при завершении учитываются как ноль.

«Выйти из занятия» сохраняет ответ 112; при ошибке ученик остаётся в форме. Несохранённый редактор статуса ДДС нужно сохранить или отменить. Закрытие карточки в журнал не является выходом из занятия. Начатые занятия, включая приостановленные, остаются в активных; доступные содержат только ещё не начатые.

Клиент подтверждает присутствие раз в 15 секунд. После аварийного закрытия сервер обнаруживает отсутствие через 45 секунд; последние несохранённые символы при таком выходе не гарантируются. Проверка сроков выполняется фоном и перед командами под блокировкой.

## Работа ДДС

Ученик управляет бригадами одной службы; остальные получатели видны в карточке. Сама служба остаётся «Добавлена», её время не меняется от действий бригад. Назначение бригад ручное.

Карточки поступают асинхронно. В сценарии задаются интервалы между ними; API сохраняет смещения от личного старта. Во время паузы занятия без лимита расписание сдвигается; при лимите продолжает идти. Новая карточка не ждёт завершения предыдущей.

У карточки есть исходная история бригад, новые сообщения и учебные цели. История задаёт уже выполненную работу и не приносит баллы. Ученик продолжает оставшиеся этапы:

`Назначена → Принята → Начало реагирования → Прибытие → Проведение работ → Завершение`.

До принятия доступна «Не принята», после — «Отказ от выполнения работ». Отмена назначения — отдельное действие. Отказы и отмена требуют причины, рабочие статусы — текста. Новое назначение после отмены начинает новый цикл.

Нормативы новых упражнений считаются от поступления карточки:

- открытие — 30 секунд;
- первая рабочая запись статуса с текстом — 180 секунд.

Назначение и отмена не считаются первой рабочей записью. Эти сроки не ограничивают завершение всех работ. В полной ситуации и контроле нормативы входят в оценку; в освоении, отработке и повторении отображаются без штрафа.

Полная ситуация требует конечного исхода и оставшегося пути реагирования. Навыковое упражнение может завершаться промежуточной целью. Неполную работу можно сдать с потерей соответствующих баллов. Исторические назначения сохраняют собственную методику.

Требование звонка действует при новом назначении бригады. Ученик сам звонит руководителю; предустановленная история не требует повторного звонка. [Телефония](TELEPHONY.md).

## API и аудит

Основные команды: `/lessons/start` для назначения, `/student/lessons/{id}/start`, `/presence`, `/leave` для личного выполнения; `/student/assignments/{id}/start` открывает карточку. В 112 ответ сохраняется через `PUT /student/attempts/{id}/card` и сдаётся через `/submit`; в ДДС используются `/dds/crews` и `/dds/submit`.

Пути полей и тела команд смотрите в Swagger. Чтение проверяет владение; запись также проверяет срок, ревизию и доступные навыки. Эталон не возвращается ученику обычным запросом карточки.

Учебный аудит фиксирует действия, сохранение, подсказки и звонки. Прокторинг хранится отдельно: события вкладки и фокуса нужны для проверки условий прохождения, а не для начисления баллов. Видео и содержательное распознавание звонков не включены.
