# Подготовка карточек из согласованных ситуаций

Преподаватель открывает **Карточки → Сгенерировать карточки**. Количество — 1–10,
параметры общие для пакета; «Случайно» выбирает совместимые значения для каждой
карточки. Результаты сохраняются в библиотеку через существующую PostgreSQL-очередь.

## Два режима

- **Заготовка + подбор формулировок ИИ** (`mode=assisted`, по умолчанию): модель
  выбирает один из двух проверенных вариантов реплики, вступление и порядок
  адреса/события. Свободный пересказ фактов отключён. Имена, адреса, числа, признаки,
  эталон и службы формирует backend. Это ограниченная композиция текста, не
  свободная генерация новой истории.
- **Заготовка без ИИ — быстро** (`mode=template`): тот же план и проверенные фразы,
  варианты выбираются по сохранённому seed. Вызова модели нет.

Если модель недоступна, превысила 90 секунд или вернула неверный выбор, применяется
текст заготовки. В карточке преподавателя видно, что использован запасной вариант.
Сетевую/модельную ошибку не скрываем под успешной работой ИИ. Ошибки БД, каталога и
прав пользователя по-прежнему не превращаются в успешную карточку.

## Библиотека

`app/data/generation_templates.json` — 37 заготовок версии `situations-v1`.
Поддержаны 101/Пожар, 102, 103, 104/Запах газа, ДТП, дорожные помехи, скопление воды,
животные (застрявшая кошка), ошибочный набор, консультация и тестовый вызов.
Молчаливый вызов обрабатывается отдельно без модели. Это начальное покрытие,
не все сочетания признаков 51 типа ЕКП. Полный список доступен в форме генерации.

Заготовка содержит стабильный ID, названия подходящих типов, допустимые объекты,
связанные признаки, ограничения по пострадавшим/доступу, заголовок и две готовые
реплики. При расширении менять версию библиотеки и проверять тесты соответствия
реальному справочнику. Учебные сюжеты не объявляются утверждёнными регламентами.

Явные значения преподавателя сохраняются. Если ни одна заготовка им не соответствует,
API возвращает 422: параметры нужно изменить или создать карточку вручную. Скрытые
поля ЕКП и несовместимые родительские/дочерние признаки не попадают в результат.
Случайный выбор предпочитает сюжеты, реже встречавшиеся в последних 50 генерациях
преподавателя, и учитывает уже выбранные карточки текущего пакета.

Не выбранные необязательные признаки не заполняются произвольно. Наличие пострадавших
согласуется с соответствующими признаками и количеством. Медицинские сюжеты и наезд
на пешехода рассчитаны на одного пострадавшего, остальные поддержанные сюжеты — до
трёх. Молчаливый вызов не содержит неизвестных адреса и обстоятельств. Служебным
вызовам не придумываются адрес происшествия, имя или возраст, если они не заданы.

Для незакреплённых флагов: вероятность пострадавших 20%, затруднённого доступа 10%,
срыва звонка 5%, отказ от медицинской помощи самостоятельно не добавляется. Сюжет и
явные параметры имеют приоритет над этими вероятностями; это учебные веса, а не
статистика реальных вызовов.

## Данные и проверка

В `ai_jobs.input.narrative` сохраняется полный снимок заготовки, версия, выбранные
факты, seed, режим и запасной вариант. Обновление JSON-библиотеки не меняет уже
зарегистрированную задачу. Версия промпта — `card-generation-v3`.

Модель получает короткий промпт без имён, адресов, телефонов и списков служб.
Ответ — три числа 0/1; дополнительные поля, свободный текст и другие значения
отклоняются. Перед сохранением готовый текст повторно сверяется с композицией по
сохранённому плану. Ошибки прежнего вида «дом 48 превратился в 4» или «двор превратился
в помещение» невозможны на этапе модельного пересказа: он больше не выполняется.
Корректность самих заготовок требует авторской проверки.

Сообщение содержит речь заявителя и доступные оператору сведения: АОН, уточнение
возраста, место и наблюдение о сохранении/срыве соединения. Таблица «при расхождении
используйте контрольные сведения» удалена. Дополнительные заданные преподавателем
признаки доступны как ответы на уточняющие вопросы; они не остаются скрытыми
критериями оценки. Тип происшествия и эталонный список служб не раскрываются
отдельной таблицей ответов.

В `ai_jobs.output.inference` — способ подготовки (`assisted`, `template`,
`template-fallback`), выбранные формулировки, метрики и причина запасного варианта.
GET карточки преподавателя возвращает `generation_method`, `generation_note`,
`generation_template`; в ученический текст технические сведения не добавляются.

Службы рассчитываются по опубликованному ЕКП. Явный список преподавателя, включая
пустой, имеет приоритет. Генератор создаёт библиотечные карточки, не назначает
самостоятельно уроки и не определяет последовательность реагирования ДДС.

## Запуск и проверка

```sh
docker compose up --build -d --wait
docker compose exec llm ollama pull qwen3:4b-instruct-2507-q4_K_M
```

CPU-модель остаётся прежней. Миграция для изменения генератора не нужна: используются
существующие JSON-поля очереди. Старая генерация v1/v2 не исполняется новым worker;
её готовые карточки сохраняются, незавершённые задачи получают понятную ошибку и
освобождают лимит очереди. Новые пакеты нужно создать заново.

Внутри Docker-образа backend доступен контрольный прогон без записи в БД:

```sh
docker compose exec -T api python scripts/evaluate_generation.py
docker compose exec -T api python scripts/evaluate_generation.py --without-model
```

Он использует реальные схемы признаков seed-справочника, печатает JSONL с условиями,
полным текстом, способом подготовки и временем. Можно выбрать сюжеты:
`--templates fire-rubbish road-collision gas-stove medical-faint wrong-number`.

Тесты: `tests/test_generation_situations.py`, `test_card_generation.py`,
`test_card_flags.py`; браузерный `e2e/card-generation-real.spec.ts` работает только
с `AUTH_ISOLATED_API=true` и `LLM_REAL_TEST=true` либо `GENERATION_TEMPLATE_ONLY=true`.
Подробный разбор реального прогона: [GENERATION_EVALUATION.md](GENERATION_EVALUATION.md).
