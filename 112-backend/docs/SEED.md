# Тестовое наполнение БД

Один скрипт `scripts/seed_demo.py` заполняет ЕКП, профили служб и, по выбранному режиму, учебные данные. Выполняйте команды из `112-backend` после запуска Compose и миграций.

## Полный демонстрационный стенд

```sh
docker compose exec -T api python scripts/seed_demo.py --database --full-demo --prefix demo --state-file /home/appuser/telephony/.demo-seed.json
```

Скрипт создаст справочник, пользователей, группы, карточки, сценарии, занятия разных форматов и готовые результаты. Демонстрационные ИИ-разборы подготовлены заранее: это не результат нового запуска модели. Работающий воркер при этом может отдельно обрабатывать появившиеся задачи.

Основные аккаунты: `demo-teacher` / `demo-teacher-123` и `demo-student` / `demo-student-123`. Остальные перечислены в итоговом выводе и [описании демонабора](FULL_DEMO.md). Пароль администратора в режиме `--database` не меняется.

## Другие режимы

| Параметр | Что добавляет |
| --- | --- |
| Без учебных флагов | ЕКП и опубликованные профили активных служб |
| `--profiles-only` | Профили для уже существующих активных служб |
| `--with-training` | Основной набор ученических занятий и данных для рекомендаций |
| `--recommendation-cards N` | Число решённых карточек для рекомендаций: 3–30, либо 0 для отключения в обычном учебном режиме |
| `--with-crew-calls` | Вместе с `--with-training`: отдельное упражнение ДДС со звонком бригаде |
| `--full-demo` | Расширенный автономный набор; включает учебные данные и упражнение со звонком |

`--full-demo` требует `--database`, не сочетается с `--profiles-only` и не отключает историю рекомендаций при значении 0.

Только справочник:

```sh
docker compose exec -T api python scripts/seed_demo.py --database --state-file /home/appuser/telephony/.catalog-seed.json
```

Если нужны новые ИИ-рекомендации по тестовым решениям, используйте обычный учебный режим и запустите сервисы `worker` и `llm`:

```sh
docker compose exec -T api python scripts/seed_demo.py --database --with-training --recommendation-cards 6 --prefix demo --state-file /home/appuser/telephony/.training-seed.json
```

Выберите один режим и постоянный файл состояния для своего набора. Команды выше — альтернативы, а не обязательные последовательные шаги.

## Повторный запуск

Используйте тот же `--prefix` и `--state-file`. Скрипт сохраняет связь с созданными записями и не удаляет прогресс. Пароли тестовых учеников и преподавателей снова устанавливаются в значение «логин + `-123`».

Файл состояния содержит служебные данные и может содержать пароли. Не публикуйте его и не добавляйте в Git. Для демостенда храните его в постоянном томе, как в командах выше.

## Запуск с хоста

После `uv sync --locked`, с настроенными `.env` и доступной БД:

```sh
uv run python scripts/seed_demo.py --database --with-training --prefix demo --state-file .demo-seed.json
```

Для генерации и хранения готовых аудиозаписей нужен доступный для записи `TELEPHONY_MEDIA_DIRECTORY`. HTTP-вариант и происхождение исходного справочника описаны в [подробной инструкции](DEMO.md). Полный список параметров:

```sh
uv run python scripts/seed_demo.py --help
```
