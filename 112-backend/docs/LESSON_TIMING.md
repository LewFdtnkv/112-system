# Время занятий и выход ученика

Окно доступности задаётся преподавателем: начало включительно, окончание не включительно. Без даты начала доступно сразу, без даты окончания нет календарного срока. `lessons.time_limit_seconds` — необязательный общий лимит; UI принимает целые минуты (1–1440). Личный отсчёт начинается по явной команде начала, не при назначении или просмотре кабинета. Прямой старт первой карточки через API также запускает занятие.

`lesson_executions` теперь есть у каждого ученика для 112 и ДДС. Сервер завершает его работу по более раннему сроку: календарное окончание или личное начало плюс лимит. Переход между карточками, повтор запроса, выход и продолжение не обнуляют лимит. Окончание одного ученика не закрывает занятие остальных. Серверный sweep работает раз в5с; команды дополнительно проверяют срок под блокировкой занятия. Непройденные карточки учитываются как0, выполненная часть автоматически оценивается; преподаватель может пересмотреть результат, даже если другие ученики ещё работают.

Без лимита минут можно выйти и продолжить: незавершённые карточки сохраняют интервалы пауз в `attempts.pauses`. UI и расчёт длительности/реакции ДДС исключают эти интервалы, включая историческую первую реакцию. В ДДС во время такой паузы новые карточки не поступают; при продолжении оставшееся расписание сдвигается на длительность паузы. Календарное окончание не сдвигается. С лимитом минут отсчёт и поступление ДДС продолжаются после выхода.

Кнопка «Выйти из занятия» доступна в журнале и учебной панели карточки. Перед явным выходом из112 сохраняется текущий черновик; при ошибке ученик остаётся в карточке. При открытом несохранённом редакторе статуса ДДС выход заблокирован до сохранения или отмены. Простое закрытие карточки возвращает в журнал и не приостанавливает занятие.

- `POST /student/lessons/{id}/start`: начать/продолжить; возвращает личное начало, срок, идентификатор посещения.
- `POST /student/lessons/{id}/presence`: подтверждение присутствия раз в15с; тело `{"session_id": "UUID"}`. Не возобновляет приостановленную работу.
- `POST /student/lessons/{id}/leave`: выход с тем же идентификатором; повтор безопасен. Запоздалый запрос предыдущего посещения получает409 и не приостанавливает новое.

Все команды доступны только назначенному ученику. Изменения карточки после выхода запрещены до явного продолжения. При смене маршрута/закрытии страницы frontend отправляет leave с keepalive; при аварийном закрытии или потере сети сервер обнаруживает отсутствие подтверждений через45с. Это верхняя погрешность определения момента аварийного выхода, а не изменение лимита занятия. Закрытие браузера не гарантирует отправку последних несохранённых символов; для гарантированного сохранения используется явная кнопка выхода.

Кабинет: `active_lessons` — начатые присутствующие занятия; `available_lessons` — новые и приостановленные. Раздельная пагинация `active_offset` / `available_offset`, по6 записей. Будущие и завершённые доступны в общей таблице. Карточки показывают заметную учебную роль, формат, срок и лимит; повторяющие заголовок статусы удалены.

Миграция0030 переносит прежний назначенный лимит на занятие, создаёт недостающие личные исполнения. Завершённые оценки не пересчитываются. Начатые незавершённые занятия переводятся в состояние выхода до явного продолжения; при наличии лимита старое личное начало сохраняется. При первом обновлении такой срок может уже истечь. Seed запускать заново не требуется.
