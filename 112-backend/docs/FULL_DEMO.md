# Полный набор для ручного тестирования

`scripts/seed_demo.py --database --full-demo` расширяет обычный учебный seed.
Он создаёт готовые результаты и оставляет отдельные задания для самостоятельного
прохождения. Миграции не добавляются, существующие занятия и оценки не удаляются.
Режим предназначен для тестовой БД; пароль администратора не меняется.

## Запуск

Из каталога `112-backend`, после применения миграций:

```bash
docker compose run --rm --no-deps -v "$PWD:/workspace:ro" -w /workspace api python scripts/seed_demo.py --database --full-demo --prefix full --state-file /home/appuser/telephony/.full-demo-state.json
```

Эта команда читает текущие исходники, использует настроенную `DATABASE_URL` и общий
том `telephony_media` для готового WAV и файла состояния. Не запускает дополнительные
зависимости и не перезапускает API/worker/frontend. Нужен уже собранный backend-образ.
Для автономного наполнения новой БД запускайте seed до подключения к ней worker:
сам seed не вызывает LLM, TTS, ASR, карты, переводчик или АТС, но уже работающий
worker независимо от seed может обрабатывать новые результаты обучения.

При запуске Python вне Docker нужны зависимости backend, `DATABASE_URL` и доступный
для записи `TELEPHONY_MEDIA_DIRECTORY`. Укажите постоянный `--state-file`.

Полный набор включает `--with-training` и `--with-crew-calls`. Он доступен только
через `--database` и несовместим с `--profiles-only`. Для рекомендаций создаётся
не менее шести завершённых карточек; `--recommendation-cards 0` здесь не отключает
историю. Старые режимы HTTP и `--with-training` сохраняют прежнее поведение.

## Учётные записи

Для `--prefix full`:

| Логин | Пароль | Что смотреть |
| --- | --- | --- |
| `full-teacher` | `full-teacher-123` | Группы, результаты, мониторинг, разборы, сценарии, генерация |
| `full-student` | `full-student-123` | Все форматы, завершённые работы, пауза, истёкший срок, сообщения |
| `full-student-good` | `full-student-good-123` | Примеры успешных результатов 112/ДДС |
| `full-student-help` | `full-student-help-123` | Подсказки, неполный адрес, спорный разбор, пересмотр преподавателя |
| `full-student-new` | `full-student-new-123` | Нетронутые задания для прохождения каждого формата |

Для администрирования используйте существующего администратора. На чистой БД
сохраняется стандартная обязательная смена его стартового пароля.
Файл состояния содержит тестовые пароли и записывается с правами `0600`.

## Покрытие экранов и функций

При стандартных параметрах на чистой БД создаются 31 занятие, 20 карточек библиотеки,
10 сценариев, 4 ученика, 1 преподаватель и 3 группы. Исходный справочник содержит
211 служб, 51 тип и 177 полей; профиль есть у каждой активной службы.

| Раздел | Готовые данные и действие для проверки |
| --- | --- |
| ЕКП, службы и профили | Исходный справочник, территории, объекты, контакты, бригады; можно искать и открывать карточки служб |
| Пользователи и профиль | Несколько учеников с разными именами, история входов/создания, синтетические аватары и ученик без фотографии |
| Группы | Основная группа с четырьмя учениками, пустая резервная для переводов, расформированная группа с событием в истории ученика |
| Карточки 112 | Пожар, ДТП, газ, ошибочный набор, консультация; есть адрес, заявитель, признаки и получатели |
| Карточки ДДС | Новая карточка и продолжение смены; исходная история, новые сообщения и цели бригад |
| Редактирование и образцы | Отдельная неиспользуемая карточка с условием 112 и упражнением ДДС, отмеченная образцом генерации |
| Учебные форматы | Освоение интерфейса, практика, отработка навыков, повторение, контроль для 112 и ДДС; у нового ученика все доступны для начала |
| Готовые результаты | Дополнительно 30 завершённых попыток: по три ученика в каждом из десяти сочетаний роли и формата; всего 38 завершённых попыток с базовым seed |
| Помощь и история | Штатно выданные подсказки, сохранения карточек, переходы бригад, отдельные наблюдения потери фокуса/возврата |
| Сроки и кабинет | Пауза с возможностью продолжения, плановое занятие через неделю, личный лимит 20 минут, отдельная работа с реально истёкшим секундным лимитом |
| Оценки и аналитика | Формальные и смешанные оценки, успешные и неполные ответы; пересмотр контрольной работы преподавателем с причиной и сохранённой историей |
| Разбор ученика и преподавателя | Готовые демонстрационные смысловые заключения и спорные критерии; ученик видит их после своей сдачи |
| Память оценивания | Общая библиотека учебных разборов и отдельный отключённый пример преподавателя; можно проверить фильтры и включение |
| Сообщения | Групповое, личное прочитанное и личное непрочитанное сообщения, счётчик непрочитанных |
| Рекомендации | Опубликованные советы на основе фактических формальных результатов, ссылки на доступную практику; подбор из методической библиотеки без модели |
| Генерация и ИИ-задачи | Два успешных результата генерации 112, отдельное готовое упражнение ДДС, демонстрационный сбой генерации для повторного запуска; вход/выход/контекст доступны в деталях |
| Телефония | Занятие с обязательным звонком руководителю; настоящий готовый WAV из штатного голосового набора, пример ошибки аудио, отключённая демостанция, четыре исторических исхода вызова |
| Отчёты и экспорт | Завершённые работы и журнал событий дают содержимое для штатных отчётов, сравнения ответов и экспорта |

Количество рекомендаций зависит от профиля навыков: оно не фиксируется искусственно.
Поле `training.card_count` сохраняет прежний смысл — карточки базового учебного
плана. Идентификаторы расширения находятся в `training.full_demo` итогового JSON.

## Что является демонстрацией

Учебные действия выполняются через обычные сервисы приложения, и баллы считает
обычная проверка. Генерация 112 использует штатные заготовки, ДДС — штатный план
с готовыми формулировками. Смысловые заключения и выбор рекомендаций явно помечены
`demo-fixture/no-model` и объяснены в видимом тексте: это примеры для интерфейса,
а не результат запуска нейросети и не проверка её качества. В очередь не оставляются
искусственные `queued/running` задачи. Явный повтор пользователем запускает обычную
функцию приложения с её текущими настройками.

История звонков помечена `demo-fixture`, не содержит `provider_call_id`, записи
разговора или подтверждения АТС и не засчитывает обязательный звонок. Для настоящего
учебного звонка требуется настроить телефонию и привязать реальную учебную станцию
к ученику. Аудиопример можно прослушать без модели. Карты, адресный поиск и перевод
требуют своих настроенных провайдеров; заполнение БД не заменяет эти интеграции.
Векторные представления примеров не подделываются: библиотека готова для просмотра,
а векторный поиск требует штатной модели эмбеддингов.

## Повтор и восстановление

Повторяйте команду с теми же `--prefix`, `--base-url` и `--state-file`.
После успешного запуска расширение возвращает сохранённый результат и не сбрасывает
попытки, сообщения, оценки, фотографии или изменения тестировщика. Общая загрузка
справочника/недостающих профилей сохраняет штатное поведение seed.
После прерывания продолжаются недостающие шаги; завершённые попытки и ИИ-задачи
переиспользуются. Не удаляйте файл состояния ради повторного запуска.
Существующий `--with-training` набор можно дополнить, передав его прежний файл
состояния и префикс. Для независимого нового набора нужны и новый префикс, и новый файл.

## Проверки

`tests/test_seed_full_demo.py` проверяет наполнение с чистой БД, чтение работ и
разборов учеником/преподавателем, непустые рекомендации, разные исходы звонков,
отсутствие задач в очереди, повтор без дублей, восстановление потерянных контрольных
записей, сохранность изменений тестировщика и восстановление настроек при исключении.
HTTP-режим и прежний учебный seed покрываются существующими `test_seed_*`.
