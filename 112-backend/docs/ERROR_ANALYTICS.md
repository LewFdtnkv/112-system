# Аналитика типичных ошибок

В кабинете преподавателя: **Аналитика → Типичные ошибки**. Отдельные выборки для
тренировок и контрольных занятий, фильтры группы, оператора и последних 30/90/365 дней.
Период относится к завершению попытки карточки, а не к дате создания занятия.

- Карточки объединяются по библиотечной карточке и роли оператора. Повторное
  использование в разных сценариях увеличивает число попыток одной строки.
- Сортировка по доле попыток с хотя бы одной ошибкой, затем по числу таких попыток.
  При числе попыток меньше пяти отображается «Мало данных»: это наблюдение,
  а не статистически надёжная оценка сложности карточки.
- В тепловой таблице каждый навык учитывается один раз на попытку. Несколько
  неверных полей адреса не превращают одну попытку в несколько ошибочных.
  Пропуск непроверяемого навыка обозначен «—», а не нулевым результатом.
- Раскрытие строки показывает до 10 проблемных полей и до 3 примеров результатов.
  Ссылки открываются в новой вкладке. Отдельная таблица показывает 10 полей с
  наибольшей долей ошибок во всей выборке, независимо от страницы карточек.
- Частично верные ответы считаются расхождениями. Применённые поправки ИИ входят
  в результат исходного поля один раз. Неуверенные выводы не считаются ошибками.
- Проверяемые ИИ попытки пока исключены и подсчитаны отдельно. При отказе ИИ
  доступны проверки по правилам с отметкой о неполноте; дополнительные службы,
  требующие смысловой проверки, не объявляются ошибкой до её завершения.
- После ручного пересмотра итога занятия карточки исключаются из этой автоматической
  статистики: пересмотр общего балла не говорит, какие отдельные ошибки подтверждены.
  Сводка оценок по сценариям по-прежнему учитывает итог преподавателя.
- Незавершённые попытки, отменённые занятия и освоение интерфейса не включаются.
  Непройденная карточка может уменьшать итог занятия, но не доказывает ошибку в поле.

`GET /api/v1/views/analytics/errors` доступен только преподавателю, только по его
занятиям. Чужая группа — 404, ученик/администратор — 403. Пагинация карточек на сервере;
выборка ограничена 1000 результатами занятий и 10000 назначениями. При превышении
нужно сузить период/группу; скрытого усечения статистики нет. Ответ содержит агрегаты
и ссылки на собственные результаты, без ответов учеников и эталонных значений.
Миграции и повторное оценивание не нужны.
