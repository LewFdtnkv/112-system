# Документация backend

[Быстрый запуск](../README.md) — установка, адреса сервисов и первый вход. Все команды в документации выполняются из корня репозитория backend, если не указано иное. Контракт HTTP доступен в Swagger запущенного API на `/docs`; пути без префикса относятся к `/api/v1`.
