# Кабинет и профиль ученика

`GET /api/v1/student/overview?active_offset=0` — собственный кабинет ученика.
`GET /api/v1/teaching/students/{student_id}/overview?active_offset=0` — профиль
доступного преподавателю ученика. Права проверяются по текущей группе или истории
назначенных этим преподавателем уроков. Чужой профиль возвращает 404; системные
роли остаются взаимоисключающими.

Ответ содержит `user`, названия `groups`, `active_lessons` и `performance`.
Ученик видит свои уроки всех преподавателей. Преподаватель видит только свои
группы, уроки и результаты, в том числе после исключения ученика из группы.
Скрытые эталоны карточек в эту проекцию не входят.

## Активные уроки

Урок доступен по датам, имеет статус active/planned, работа ученика не сдана.
Начатые идут первыми, затем ближайший срок и дата запуска. Отдельная пагинация
по 6 записей не позволяет длинной истории законченных уроков скрыть текущие.
Если при повторном запросе страниц стало меньше, `offset` ограничивается последней
непустой страницей. Будущие и просроченные задания доступны в общей истории.
Фактическую возможность выполнения и дедлайны повторно проверяет workflow.

## Успеваемость

- `overall_percent` — среднее арифметическое `100 * score / max_score` по всем
  оценённым урокам. У каждого урока одинаковый вес, шкалы баллов могут различаться.
- `recent_percent` — такое же среднее по последним 5 оценённым урокам по времени
  завершения работы ученика. `recent_count` показывает фактическое число, если их меньше 5.
- Учитывается последняя ревизия итоговой оценки, включая пересмотр преподавателя.
  Пересмотр старого урока не делает этот урок новым в списке последних результатов.
- Неоценённые уроки не входят в среднее. При отсутствии оценок — null, реальный
  нулевой балл — 0. Пропущенные карточки уже учтены в итоговой оценке урока.
- `total_lessons`, `completed_lessons`, `graded_lessons` — счётчики по той же
  области доступа. `recent_lessons` — максимум 5 строк без содержимого попыток.

`LessonRow.completed_at` отражает завершение работы ученика, а не дату пересмотра
оценки. Для незаконченной работы — null. У старых завершённых уроков без времени
попытки используется время окончания, запуска или создания урока.

`GET /api/v1/views/lessons?student_id=...` добавляет фильтр ученика к существующей
пагинированной истории преподавателя с той же проверкой доступа. Старая ручка
`/teaching/students/{student_id}` оставлена для совместимости.

Миграция БД не требуется. Агрегаты рассчитываются сервером без загрузки всех
попыток в память: фиксированное число запросов, ограниченные списки в ответе.
Проверки расчёта, ревизий, сроков, пагинации и доступа: `tests/test_student_overview.py`.
