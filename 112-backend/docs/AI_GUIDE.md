# Как используется ИИ

ИИ выполняет фоновые задачи: создаёт условия карточек, проверяет смысл ответов и готовит рекомендации. Пользователь не должен ждать модель в открытом HTTP-запросе. Состояние задач видно администратору в [мониторе](AI_JOB_MONITOR.md).

## Генерация карточки

Преподаватель задаёт число карточек и параметры. Фиксированные значения сохраняются, случайные выбираются заново для каждой карточки до обращения к модели. ИИ получает конкретные факты: тип, адрес, заявителя, пострадавших и службы.

Модель пишет сообщение заявителя, после чего проверки сравнивают текст с исходными фактами. Номер телефона передаётся в АРМ, а не отдельной фразой в условии. Пол не требуется объявлять словами; уточнения разговора отделяются от речи заявителя абзацем. Форматы сообщения допускают неполные сведения, например СМС без имени.

Для ДДС запускается отдельная задача: она получает готовую карточку и выбранные состояния бригад. Если условие ДДС не прошло проверку, сама карточка сохраняется без этого дополнения. Подробнее: [генерация 112](CARD_GENERATION.md), [генерация ДДС](DDS_GENERATION.md).

## Что такое память ИИ

Память хранит примеры. Перед запросом система находит близкие по смыслу и добавляет подходящие в промпт — это RAG. Текст и векторы хранятся в PostgreSQL с pgvector; эмбеддинги строит `qwen3-embedding:0.6b`.

| Вид примера | Как используется |
| --- | --- |
| Разбор оценивания | Показывает критерий, условие, ответ, вердикт и обоснование |
| Исправление преподавателя | Помогает учесть похожую ситуацию в будущей проверке |
| Карточка для генерации | Служит примером хорошего условия и согласованного решения |

В преподавательской памяти ИИ можно создать разбор, посмотреть примеры, отключить или удалить ненужный. На вкладке генерации отдельно видны карточки, разрешённые в качестве примеров. Переключатель доступен в нижней панели просмотра карточки.

## Как повлиять на оценивание

1. Откройте результат ученика и нужный критерий.
2. Укажите вердикт и короткое обоснование исправления. Сохраните разбор для будущих проверок; при необходимости создайте его вручную в памяти ИИ.
3. Проверьте, что пример включён. Неподходящие примеры можно отключить.

Пересмотр общего балла сам по себе не создаёт разбор по каждому полю. Новые примеры не переоценивают старые работы и не меняют веса модели. Пример может не попасть в следующий запрос, если не подходит по критерию или контексту. [Правила отбора и доступа](ASSESSMENT_MEMORY.md).

## Рекомендации после занятия

Помощник опирается на подтверждённые ошибки и историю навыков. Он даёт рекомендации по дальнейшей учёбе, а не подсказки в текущей карточке. Если найдена подходящая практика, ученик получает направление на месяц и может создать по нему одно личное занятие.
