# Записи и озвучка

Записи добавляются в редакторе карточки. Для 112 выбираются варианты сообщения заявителя, для ДДС — пары «приветствие / подтверждение» руководителя. На одну карточку можно добавить до десяти вариантов. Библиотека «Записи звонков» показывает готовность и использование записей.

## Готовый файл

Формат — WAV PCM, моно, 8000 Гц, 16 бит, не более **1 МиБ**. Сообщение заявителя — до 65 секунд, каждая реплика бригады — до 20 секунд. Проверяется содержимое, а не расширение.

```sh
ffmpeg -i source.wav -ac 1 -ar 8000 -c:a pcm_s16le lesson.wav
```

Все варианты одной карточки должны передавать одинаковые существенные сведения. Система не распознаёт содержание загружаемого аудио; автор проверяет его сам.

Загрузка создаёт неизменяемую запись преподавателя. Отмена редактора не удаляет запись из библиотеки. Привязки сохраняются вместе с карточкой и попадают в снимок сценария. Для выбранных собственных записей вариант фиксируется на попытку и контакт; повторное открытие его не меняет.

## Озвучка текста

В редакторе выберите «Озвучить текст заявителя» либо «Создать голос бригады из текста». Укажите голос, текст, дождитесь подготовки, прослушайте и добавьте запись в карточку. Для бригады приветствие и подтверждение создаются одним голосом.

Подготовка продолжается после закрытия окна. Ошибочную запись можно повторить; изменение текста или голоса создаёт новую запись. До готовности использование в карточке недоступно.

| Голос Piper | Модель | Лицензия датасета по MODEL_CARD |
| --- | --- | --- |
| Денис | `ru_RU-denis-medium` | CC0 |
| Дмитрий | `ru_RU-dmitri-medium` | CC0 |
| Ирина | `ru_RU-irina-medium` | Unknown — не указана |
| Руслан | `ru_RU-ruslan-medium` | CC BY-NC-SA 4.0 |

Piper 1.8.0 распространяется по GPL-3.0. MODEL_CARD голосов включены в образ рядом с моделями в `/opt/voices`. Первоисточник голосов — [piper-voices](https://huggingface.co/rhasspy/piper-voices/tree/c10ece1aade47bb51c153c893d14e5bf8e5b7117/ru/ru_RU).

## Воркер и зависимости

`speech-worker` входит в основной Compose, использует CPU, отдельно от Ollama и Asterisk. Модели скачиваются при сборке с проверкой SHA256; синтез работает без интернета. Для обновления:

```sh
docker compose up -d --build api speech-worker frontend
```

Piper и scipy выделены в группу uv `tts`; API-образ их не содержит:

```sh
uv sync --locked --no-dev --group tts
```

Файлы моделей загружаются отдельным скриптом сборки. Воркер держит в памяти выбранный голос. Сохраняются WAV 8 кГц и PCM 16 кГц для G.722. Во время звонка проигрывается готовое аудио, без ожидания TTS или LLM.

## Очередь и API

Очередь хранится в PostgreSQL. Захват имеет срок и токен, синтез выполняется вне транзакции в отдельном процессе. До трёх автоматических попыток, тайм-аут 180 секунд. У преподавателя допускается до 20 незавершённых реплик.

Текст заявителя — до 1000 символов, каждая реплика бригады — до 200. Слишком длинный результат отклоняется, а не обрезается. Кэш учитывает текст, голос, версию и назначение, доступ остаётся привязанным к владельцу.

Пути относительно `/api/v1/telephony/recordings`: список и загрузка — корень, голоса — `/voices`, синтез — `/synthesize`, повтор — `/{id}/retry`, прослушивание — `/{id}/wav`. Эти операции доступны преподавателю для собственных записей. `request_id` защищает от повторной постановки одинаковой команды.
