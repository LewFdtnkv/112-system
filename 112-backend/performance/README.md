# Нагрузочные проверки

Инструменты для проверки пользовательских сценариев и пропускной способности API на отдельной тестовой БД. Locust моделирует работу учеников, HTTPX создаёт поток с заданным RPS.

## Содержимое

| Файл или каталог | Назначение |
| --- | --- |
| `compose.yaml`, `Dockerfile`, `requirements.txt` | Изолированный стенд и зависимости генератора |
| `seed.py` | Подготовка тестовых пользователей, карточек и занятий |
| `locustfile.py` | Сценарии 112/ДДС, отчёты, авторизация и чтение без пауз |
| `capacity.py` | Ступенчатая нагрузка с заданным RPS |
| `monitor.py`, `metrics.py` | Метрики ресурсов и обработка результатов |
| `results/` | Выбранные итоговые результаты и параметры последнего прогона |
| `artifacts/` | Локальные отчёты и тестовые реквизиты; исключены из Git |

## Последний результат — 27.09.2026

API: 4 CPU, 4 процесса; PostgreSQL: 4 CPU. Каждому выделено 2 ГиБ памяти. Генератор работал на том же Docker-хосте. ИИ и SIP отключены.

| Нагрузка | HTTP RPS | p95 | Максимум | Ошибки |
| --- | ---: | ---: | ---: | ---: |
| 20 учеников, паузы между действиями | 16,25 | 47 мс | 640 мс | 0 |
| 100 учеников, паузы между действиями | 74,10 | 110 мс | 1112 мс | 0 |
| 20 читателей без пауз | 702,31 | 61 мс | 558 мс | 0 |
| 100 читателей без пауз | 509,57 | 420 мс | 3559 мс | 0 |

Пользовательские прогоны длились 90 секунд, чтение — около минуты. В строках чтения исключены авторизация и служебные запросы. p95 — время, в которое уложились 95% ответов.

При 100 работающих учениках все измеренные ответы были быстрее 2 секунд. Максимум отдельной смеси чтений — около **700 RPS**; 1000 RPS не подтверждены. При 100 читателях без пауз очередь выросла и отдельные ответы превысили 2 секунды. Эти короткие прогоны не определяют производительность записи, ИИ или звонков.
