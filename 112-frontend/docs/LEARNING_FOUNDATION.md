# Учебные режимы и помощь

Преподаватель выбирает полную учебную ситуацию, отработку навыков, повторение
выбранных навыков или контроль. В полной ситуации и контроле выбора навыков нет.
Освоение интерфейса и разбор примера остаются недоступными.

В отработке/повторении остальные поля подготовлены и заблокированы. API дополнительно
защищает их от изменения. Для ДДС отдельно выбираются назначение и статусы бригад;
при отработке статусов бригады уже назначены системой. Подготовленная часть не
участвует в оценке. Не подходящие под выбранные навыки карточки отклоняются при запуске.

Вместо настройки времени и текстового/визуального режима преподаватель выбирает
допустимую глубину помощи. Напоминание цели показывается текстом, объяснение
подсвечивает нужный блок, эталонное решение раскрывает значение или следующий шаг.
Сервер определяет шаг по сценарию и фактической работе. Автоматическое напоминание
после паузы не раскрывает ответ. В контроле подсказок нет.

Перед запросом сохраняется черновик; после изменения подсказка и подсветка исчезают.
Выданная помощь видна преподавателю в журнале и сводке результата. Штрафа за неё
нет. Свободное описание и адрес без структурированных полей проверяются только
на наличие текста — это явно указано в настройке/критериях.

Новые занятия ДДС выполняются через бригады, служба остаётся «Добавлена».
Сведения сценария пока доступны всем пакетом, без имитации поступления сообщений.
Исторические задания и результаты сохраняют прежний процесс; назначьте новое
занятие для проверки новых режимов.

## Архитектура

- `entities/training/types/learning.ts` — контракт v2; `model/learning.ts` — подписи
  и начальные значения; `ui/LearningSummary.tsx` — общее представление условий.
- `features/lesson-launch` — форма, выбор навыков и политики помощи.
- `features/learning-assistance` — TanStack Query mutation, отображение помощи
  и её временное состояние; типы, стили, model и UI разделены по FSD.
- `pages/training-workspace` связывает помощь, сохранение и контекст АРМ.
- `widgets/incident-card` получает область редактирования через существующий
  контекст; API/учебные сценарии не перенесены в UI-библиотеку.

Серверный кэш остаётся в Query. В Zustand не копируются карточки или ответы подсказок.
Длительность, самостоятельность, раздельные результаты тренировок и контроля
сохраняют прежний смысл. ИИ и обучение интерфейсу этой задачей не подключены.

Контракт, миграция и правила: `112-backend/docs/LEARNING_FOUNDATION.md`.
Проверки: `e2e/learning.spec.ts`, `e2e/learning-assistance.spec.ts`, реальный HTTP
цикл на отдельной тестовой БД. Node и браузер запускаются в Docker.
