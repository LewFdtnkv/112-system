# Форматы занятий и помощь

| Формат                  | Что делает ученик                                              |
| ----------------------- | -------------------------------------------------------------- |
| Освоение интерфейса     | Проходит шаги с подсветкой элементов и пояснениями             |
| Полная учебная ситуация | Самостоятельно обрабатывает всю карточку с разрешённой помощью |
| Отработка навыка        | Выполняет выбранную часть работы; остальное подготовлено       |
| Повторение              | Повторяет выбранные навыки на назначенном сценарии             |
| Контроль                | Выполняет полную ситуацию без подсказок                        |

«Разбор примера» в интерфейсе недоступен. Повторение пока не подбирает карточки автоматически по прежним ошибкам.

## Сопровождение интерфейса

При открытии карточки ученик сначала читает условие и нажимает «Продолжить». Затем подсветка показывает нужную область и объясняет действие. Кнопка отключения сопровождения находится на поясняющей карточке.

Для точных ответов переход выполняется после правильного заполнения. Если ответ неверен, подсказка появляется после паузы во вводе. Для свободного текста требуется подтверждение ученика. Структурированный адрес заполняется отдельными полями; подсветка должна включать всю нужную область, а не только страну.

## Подсказки

Преподаватель задаёт допустимую глубину помощи. Напоминание говорит о цели, объяснение помогает выполнить действие, показ решения раскрывает нужное значение или шаг. Доступность и содержание определяются сервером по уже выполненным действиям.

В отработке и повторении подготовленные поля заблокированы и не входят в оценку. В полной ситуации и контроле отдельные навыки не выбираются. Использованная помощь сохраняется в журнале; сам факт подсказки не вычитает баллы.

ДДС работает с бригадами своей службы. Карточки поступают по расписанию независимо от завершения предыдущих. Подробности: [процесс ДДС](../../112-backend/docs/QA4_WORKFLOW.md), [время и паузы](../../112-backend/docs/LESSON_TIMING.md).

## Где искать код

- `entities/training` — контракт, подписи форматов и общая сводка настроек.
- `features/lesson-launch` — назначение занятия.
- `features/learning-assistance` — помощь и её отображение.
- `pages/training-workspace` — связь подсказок с сохранением и рабочим местом.
- `widgets/incident-card` — поля АРМ и области подсветки.
