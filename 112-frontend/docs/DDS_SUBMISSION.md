# Завершение упражнения ДДС

Кнопка в нижней панели открывает общий `ConfirmDialog`, а не `window.confirm`.
Подтверждение отправляет команду завершения с актуальной ревизией попытки;
отмена ничего не отправляет. Во время запроса кнопки диалога блокируются.
Ошибка API показана в самом диалоге, его можно закрыть или повторить запрос.
После успешного ответа сервера на месте кнопки видно «Упражнение завершено».
Правила завершения и оценивания на backend не менялись.

При расследовании 27.09.2026 у тестового ученика звонки были подтверждены,
API возвращал `can_finish=true`, но в аудите отсутствовали команда завершения
и её отказ. Точную причину отсутствия запроса в браузере пользователя установить
не удалось. Воспроизведён отказ старой кнопки при подавленном native confirm;
новая реализация не зависит от разрешения браузера на такие окна.

Проверки: build, lint/FSD, 201 Vitest; desktop/mobile в Firefox и Chromium на
API-фикстурах. Регрессия `e2e/dds-submit.spec.ts` проверяет отмену, ошибку API,
повторную отправку и успешное завершение при принудительно отключённом
`window.confirm`. Старый real-API сценарий обновлён для нового диалога;
в этой задаче он не запускался. Попытка пользователя не завершалась за него.
