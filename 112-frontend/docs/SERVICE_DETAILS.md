# Карточка службы администратора

В разделе «Службы и ЕКП» нажатие на строку службы (или Enter/пробел на строке) открывает карточку. В ней показаны код, короткое и полное наименования. Кнопка «Редактировать службу» открывает форму; после сохранения обновляются карточка и список. Код существующей службы неизменяем.

В карточке видны только связанные профили ДДС, включая опубликованные версии и черновики. Нажатие на профиль открывает существующий редактор с территориями, объектами, контактами и бригадами. Новый профиль из карточки автоматически закрепляется за этой службой. После закрытия профиля пользователь возвращается к карточке службы. Общий список профилей сохранён.

API `GET /api/v1/admin/service-profiles` принимает необязательный UUID `service_id`. Фильтр применяется до подсчёта и пагинации. Права доступа не изменены; миграция не требуется.

Проверки: 11 backend-тестов каталога/ДДС на отдельной PostgreSQL, frontend build/lint/FSD, сценарий `e2e/service-dialog.spec.ts` в Chromium и Firefox. Браузерные изменения данных проверяются на API-фикстурах. На рабочем API выполнена только проверка чтения профилей двух служб. Скриншоты: `docs/screenshots/service-dialog`.
