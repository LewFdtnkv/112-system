# Черновик ответа оператора 112 в браузере

Используется уже подключённый Zustand: `persist` и `createJSONStorage` поверх
localStorage. Новых зависимостей нет. Серверные данные и запись по API остаются
в TanStack Query. Статусы, оценка и сроки занятия определяются сервером.

## Поведение

- Изменённые поля сразу сохраняются в браузере. Ключ отдельный для пользователя
  и попытки: `system112-draft-v1:<userId>:<attemptId>`.
- После повторного входа тем же пользователем и открытия той же попытки
  восстанавливается несинхронизированный ввод. Поля другой попытки не подставляются.
- Автосохранение проверяет изменения раз в секунду. После сетевого сбоя/5xx
  повторяет отправку через пять секунд, при возвращении сети — сразу.
  Ошибки валидации требуют исправления данных, конфликт версии — решения ученика.
- Локальная копия удаляется только после подтверждения её записи сервером.
  Если во время запроса введён новый текст, сохраняются новые поля и новая базовая
  ревизия; затем отправляется следующий снимок.
- Если ревизия на сервере изменилась, предлагается сохранить свой черновик либо
  загрузить серверную версию. Перед выбором серверная попытка перечитывается;
  дальнейшая запись всё равно защищена `expected_revision`.
- Завершённая или прерванная сервером попытка не восстанавливается как редактируемая.
  Её локальный черновик очищается при открытии/получении конечного состояния.
- Повреждённые данные браузера не подставляются в форму. Недоступное/переполненное
  хранилище и изменение ключа другой вкладкой показывают предупреждение;
  текущий текст остаётся в памяти формы. Вторая вкладка не затирает чужой черновик.

## Границы

Это резервная копия несохранённых полей, а не автономное приложение: для открытия
занятия после перезагрузки нужны авторизация и доступ к API. Сдача упражнения,
оповещение служб, таймеры и подсказки требуют сервера. Офлайн-время не продлевает срок.
Аудит действий не переносится в этот store. Редактор библиотечных карточек и
команды бригад ДДС этой доработкой не изменены.

localStorage относится к конкретному браузеру и origin. Его очистка удалит
несинхронизированный черновик; приватное окно не гарантирует сохранность после
закрытия. На другом устройстве доступны только подтверждённые сервером данные.
Ключ пользователя разделяет восстановление, но не шифрует данные в браузере.

## Код и проверки

- `shared/lib/localDraft.ts`: Zustand persist, проверка формата, защита подтверждения.
- `pages/training-workspace/model/useAttemptDraft.ts`: восстановление и синхронизация
  конкретной попытки; записи сериализуются существующим scope TanStack Query.
- `AttemptDraftNotice`: уведомления внутри панели задания, без изменения стилей АРМ.
- `localDraft.test.ts`, `validDraftFields.test.ts`: повреждения, изоляция, переполнение,
  параллельный ввод/вкладки.
- `e2e/local-draft.spec.ts`: перезагрузка, сеть, две версии, ввод во время запроса,
  завершённая попытка. Браузерные проверки работают на API-фикстурах.
