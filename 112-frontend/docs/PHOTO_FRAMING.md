# Настройка фотографии профиля

При выборе PNG/JPEG открывается общий редактор для собственного профиля и
административного редактирования пользователя. Круг соответствует отображению
аватара. Фото можно перемещать указателем/пальцем/стрелками клавиатуры, менять
масштаб от 50% до 300% и возвращать исходное положение. Начальный масштаб вмещает
весь прямоугольник исходной фотографии; уменьшение допускает белые поля.

До подтверждения сервер не получает фотографию. Отмена сохраняет старый аватар;
после ошибки отправки можно повторить сохранение с прежними настройками.
Сохраняется квадратный JPEG 512×512, совместимый с существующей нормализацией API.
Лимиты исходника сохранены: PNG/JPEG до 2 МБ и 16 мегапикселей. Исходник и настройки
кадрирования отдельно не хранятся: для повторной настройки нужно выбрать файл снова.

Реализация находится в `features/account-profile`: UI диалога, локальное состояние
и события в model, типы в types, геометрия/экспорт в lib, оформление в styles.
Загрузка использует существующую TanStack Query mutation с обновлением всех фото
пользователя. Дополнительных зависимостей, API и миграций нет.

Проверки: unit-тесты геометрии и ограничений, Playwright `photo-crop.spec.ts`,
регрессии `interface-updates.spec.ts` и `user-photos.spec.ts` в Chromium/Firefox.
Проверены отмена, перемещение, масштаб, сброс, повтор после ошибки, повреждённый
файл, выходной JPEG 512×512 и отсутствие преждевременного сохранения профиля.
Снимки: `docs/screenshots/photo-crop/`.
