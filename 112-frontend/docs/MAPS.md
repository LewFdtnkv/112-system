# Карта происшествия

В карточке 112 нажмите значок карты рядом с адресом. В окне «Карта происшествия»
щелчок ставит метку, её можно перетаскивать. «ОК» подтверждает координаты и закрывает
окно; «Отмена»/крестик не меняют карточку. Можно ввести широту/долготу вручную и
нажать «Показать точку». Применённые координаты сохраняются вместе с черновиком,
восстанавливаются при открытии и доступны в сданной карточке для просмотра.
Текстовые поля адреса не перезаписываются. Вызовы геокодера с адресом/данными
заявителя не выполняются. SDK загружается только при открытии карты.

## Подключение

Нужен ключ **JavaScript API Яндекс.Карт 2.1**, ограниченный доменом фронтенда в
[кабинете разработчика](https://developer.tech.yandex.ru/keys/). Интеграция использует
официальные [события клика](https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/examples/cases/event_properties)
и [Placemark](https://yandex.ru/dev/jsapi-v2-1/doc/ru/v2-1/ref/reference/Placemark).

В `public/map-config.js` укажите браузерный ключ:

```js
window.SYSTEM112_MAP_CONFIG = { apiKey: "ключ JavaScript API" };
```

После этого пересоберите frontend привычной командой Docker Compose.
Файл копируется в dist и читается браузером при загрузке страницы. Для настройки
без пересборки создайте локальный файл вне Git, например `map-config.local.js`,
и подключите его volume через локальный Compose override:

```yaml
services:
  frontend:
    volumes:
      - ./map-config.local.js:/usr/share/nginx/html/map-config.js:ro
```

Путь слева относителен Compose-файлу. После изменения runtime-конфигурации
перезагрузите страницу. Ключ JavaScript API виден браузеру по назначению;
ограничение разрешённых доменов настраивается у Яндекса. Персональные настройки
ключа не коммитить. Для dev/build также поддерживается `VITE_YANDEX_MAPS_API_KEY`,
если переменная передана **в процесс Vite внутри Docker**. Приоритет у runtime-файла.
Просто environment контейнера Nginx переменную Vite не меняет.

## Ограничения и проверки

Согласован онлайн-режим Яндекса; локальная карта для изолированной сети — отдельный
этап. Без ключа/интернета показывается понятное сообщение, карточку по-прежнему
можно заполнить и сохранить. Загрузка ограничена 15 секундами, доступен повтор.
Система не маскирует отсутствие провайдера случайной картой.

Проверены адаптер клика/перетаскивания/закрытия на тестовом SDK, отсутствие записи
до «ОК», отмена, диапазоны и сохранение координат через реальный тестовый backend.
Рабочий ключ в среде разработки не предоставлен: отображение живых тайлов Яндекса
нужно проверить после подключения своего ключа. Снимок `card-map-unconfigured.png`
показывает именно неподключённый провайдер, а не действующую онлайн-карту.
