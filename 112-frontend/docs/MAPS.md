# Карта происшествия

В карточке 112 нажмите значок карты рядом с адресом. В библиотеке карточек при
создании или редактировании используйте кнопку «Указать точку на карте» в блоке
адреса. В окне «Карта происшествия»
можно найти адрес, выбрать один из результатов, поставить точку щелчком или
перетащить метку. После поиска или изменения точки карта пытается определить
обратный адрес. «ОК» применяет координаты и найденные части адреса к черновику;
«Отмена»/крестик не меняют карточку. Координаты также можно ввести вручную и
показать на карте. Применённые данные сохраняются вместе с черновиком,
восстанавливаются при открытии и доступны в сданной карточке для просмотра.

Карта работает через JavaScript API Яндекс.Карт. Поиск и обратное
геокодирование выполняются через DaData по защищённому backend-прокси, поэтому
его токен не попадает в браузер.

## Подключение

Для отображения карты нужен ключ **JavaScript API Яндекс.Карт 2.1**. Ограничьте
его доменом фронтенда в
[кабинете разработчика](https://developer.tech.yandex.ru/keys/). Без ключа
ручной ввод координат остаётся доступен, а карта выводит понятную ошибку.

Для поиска добавьте `DADATA_API_KEY` в `112-backend/.env`. Фронтенд обращается
к `/api/v1/addresses/*`; токен виден только API-контейнеру.

В `public/map-config.js` укажите браузерный ключ:

```js
window.SYSTEM112_MAP_CONFIG = { apiKey: "ключ JavaScript API" };
```

При запуске через текущий `112-backend/compose.yaml` достаточно указать
`VITE_YANDEX_MAPS_API_KEY` в `112-frontend/.env`: Compose передаёт его только
запущенному Nginx-контейнеру, а entrypoint создаёт `map-config.js` при старте.
Ключ не попадает в слой Docker-образа. Пересоздайте frontend:

```bash
docker compose up -d --build --force-recreate frontend
```

Файл `map-config.js` читается браузером при загрузке страницы. Для настройки
без пересборки можно создать локальный файл вне Git, например `map-config.local.js`,
и подключить его volume через локальный Compose override:

```yaml
services:
  frontend:
    volumes:
      - ./map-config.local.js:/usr/share/nginx/html/map-config.js:ro
```

Путь слева относителен Compose-файлу. После изменения runtime-конфигурации
перезагрузите страницу. Ключ JavaScript API виден браузеру по назначению;
ограничение разрешённых доменов настраивается у Яндекса. Персональные настройки
ключа не коммитить. Для dev/build также поддерживается `VITE_YANDEX_MAPS_API_KEY`,
если переменная передана **в процесс Vite внутри Docker**. Приоритет у runtime-файла.
Просто environment контейнера Nginx переменную Vite не меняет.

## Ограничения и проверки

Для изолированной сети нужны собственные тайлы и корпоративный геокодер — это
отдельный этап. Без интернета ручной ввод координат остаётся доступным. Загрузка
геокодера ограничена 15 секундами; ошибка не мешает заполнить и сохранить карточку.

Проверены адаптер клика/перетаскивания/закрытия, отсутствие записи до «ОК», отмена,
диапазоны и сохранение координат через реальный тестовый backend. Рабочий ключ в
среде разработки не предоставлен: поиск и обратное геокодирование нужно проверить
после подключения ключа к разрешённому домену.
