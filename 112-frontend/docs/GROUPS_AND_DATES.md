# Расформирование групп и очистка дат

Преподаватель расформировывает собственную группу кнопкой в таблице групп или в окне её
состава. Перед отправкой показывается подтверждение с последствиями. Ученики исключаются
из этой группы; учётные записи, назначенные занятия, сообщения и результаты сохраняются.
Продолжение ранее назначенных занятий разрешено. Группа исчезает из списков для новых
назначений и переводов. Для нового набора создаётся новая группа.

Feature `group-disband` вызывает `POST /groups/{id}/disband`; TanStack Query обновляет
списки групп, участников и сведения об учениках. Ошибка остаётся в диалоге, запрос можно
повторить. Backend требует миграцию `0020_disband_groups`.

Общий `shared/ui/DateTimeField` сохраняет нативный календарь и добавляет кнопку
«Очистить дату и время». Она очищает и частично введённую дату, возвращает фокус полю
и не отправляет форму. В назначении занятия пустое начало означает доступность сразу,
пустое окончание — отсутствие общей даты окончания. Отдельный лимит на карточку сохраняет
своё действие. Очищенные даты не передаются в API.

Проверка интерфейса: `e2e/groups-and-dates.spec.ts` на тестовых ответах API.
