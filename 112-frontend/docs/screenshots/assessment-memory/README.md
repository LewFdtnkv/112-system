# Память ИИ

Браузерная проверка на API-фикстурах, Chromium desktop/mobile:
- library / library-mobile — отдельная вкладка преподавателя с поиском и фильтрами;
- library-detail — полный разбор, отключение/удаление/восстановление;
- editor / saved — явное сохранение исправления из результата работы;
- teacher / arm — результат после отзыва и прежний вид АРМ.

Проверены доступ только преподавателю, публикация/отзыв, личное отключение,
подтверждение удаления и восстановление. Серверные права и влияние на pgvector
проверяются отдельно реальным FastAPI/PostgreSQL. Тесты:
`e2e/assessment-memory.spec.ts`, `e2e/assessment-library.spec.ts`.
