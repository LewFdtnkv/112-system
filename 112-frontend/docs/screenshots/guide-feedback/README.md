# Исправление после ввода — 26.09.2026

Сначала сопровождение объясняет действие без готового ответа. Через две секунды
после последнего изменения проверяется сохранённая работа. Только неверный
непустой точный ответ получает отдельное пояснение с правильным значением.
Новый ввод скрывает пояснение и отменяет незавершённый запрос. Для адреса
исправляются только неверные части; пустые поля не объявляются ошибкой.
Свободный текст по-прежнему подтверждается кнопкой «Продолжить».

`*-initial.png` — первый показ без ответа, `*-incorrect.png` — после неверного
ввода и паузы. `mobile.png` — общий адресный шаг на узком экране. Снимки лично
просмотрены. Firefox и Chromium работают в Docker, данные браузерных тестов
имитируются API-фикстурами. Реальный backend отдельно проверен интеграционными
тестами на временной PostgreSQL.

Проверены отсутствие проверки при непрерывном вводе, сброс двухсекундной паузы,
исчезновение исправления при новом вводе, ожидание пустого дома после верной улицы
и переход к свободному описанию. Существующие проверки поиска/гайда/ДДС/footer
также прошли. Build, lint/FSD и полный обязательный backend pre-commit успешны.
