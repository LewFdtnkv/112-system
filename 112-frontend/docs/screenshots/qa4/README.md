# QA4: проверенные экраны

- `dds-1440.png`, `dds-390.png`: норматив открытия 30 секунд и первой записи с текстом 3 минуты; таймер записи продолжается после назначения бригады.
- `refusal-1440.png`, `refusal-390.png`: отдельное решение «Не принята», обязательная причина, сохранённый компактный редактор статуса.
- `group-1440.png`, `group-390.png`: сводка преподавателя, ссылка на исходную работу, рекомендации и отметка ручного пересмотра; таблица прокручивается на узком экране.
- `territory.png`: территориальный получатель дополняет общую службу, задаются части адреса.

Итоговые снимки сделаны в Firefox на API-фикстурах и лично просмотрены. Поведение
также проверено в Chromium; backend-контракт отдельно проверен интеграционными
tестами на PostgreSQL. Варианты отказа на снимке синтетические, не записи учеников.
