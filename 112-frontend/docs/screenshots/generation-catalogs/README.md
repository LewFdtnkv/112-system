# Имена и московские адреса

Форма генерации: зависимые варианты улицы/дома, атрибуция адресного набора,
случайная сборка имени и возможность задать своё ФИО/ФИ и пол.
`addresses.png`, `callers.png`, `mobile.png` создаются тестом
`e2e/generation-catalogs.spec.ts` на API-фикстурах, соответствующих
новым встроенным данным. АРМ ученика этим изменением не перерабатывается.
