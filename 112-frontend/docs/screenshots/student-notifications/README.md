# Непрочитанные сообщения ученика

Колокольчик в верхней панели кабинета показывает общее число непрочитанных
сообщений преподавателей и рекомендаций по дальнейшему обучению. В АРМ его нет.
По нажатию открывается список только непрочитанных сообщений с постраничной
навигацией. Открытие списка не помечает сообщения прочитанными: для этого есть
кнопка «Прочитано» у сообщения. Она обновляет список, счётчик и сообщения кабинета.

Счётчик обновляется каждые 15 секунд и при открытии. Отдельный запрос
`GET /student/messages/summary` возвращает `unread_count` без загрузки текстов;
список использует `GET /student/messages?unread_only=true`. Данные и обновление
кэша ведёт TanStack Query. При ошибке счётчика показывается «!», а не ложный ноль.

Снимки Chromium и Firefox сделаны на API-фикстурах (25 непрочитанных сообщений),
desktop 1366×900 и mobile 390×844. Проверены прочтение, переход страниц, обновление
при повторном открытии, пустой список, ошибка счётчика, закрытие Escape и отсутствие
колокольчика у преподавателя и внутри АРМ. Backend отдельно проверяет доступ только
к своим сообщениям и счётчик за пределами первой страницы.
