# Справочник и зависимые поля

Проверено на отдельной БД с реальным API, Node/Chromium в Docker.

- [101: улица](101-street.png)
- [101: транспорт](101-transport.png)
- [Редактор условий показа](catalog-visibility-editor.png)

При смене ветки скрытые ответы удаляются. Backend отклоняет присланные скрытые
поля. Переименование ключа в редакторе обновляет ссылки в условиях показа.
Названия и показанные ветки 101 сверены с КАРТОЧКА 112.docx. Остальные поля
и маршруты содержат учебные дополнения; происхождение зафиксировано в backend.
