# Проверка Query / Zustand — 22.09.2026

- `chromium-dds.png`, `firefox-dds.png`: действующий API, завершённое занятие
  демонстрационного ученика. Ответы и статусы не изменялись. Проверены вход через
  Enter, восстановление после перезагрузки, плитки службы/бригады, выход с очисткой
  хранилища. Закрытие и повторное открытие свежей карточки выполняют всего один GET.
- `operator-mocked.png`: карточка 112 в Chromium с тестовыми ответами API.
  Сохранён регрессионный тест повторного открытия без второго GET в
  `e2e/training-flow.spec.ts`. Завершённой карточки 112 в текущей БД для такой
  проверки не было; активные попытки не изменялись.

Снимки лично просмотрены после отключения анимаций. Firefox проверен в Linux
Docker, не в macOS. Node, сборка и браузеры запускались в Docker.

Проверки: 126 Vitest, 6 Playwright (авторизация и рабочее место), production build,
ESLint и FSD. Новые модульные проверки покрывают порядок сохранений и ревизий,
ошибку и повтор, отмену устаревшего GET, сохранность несохранённого ввода при
обновлении Query-кэша и восстановление только токенов через Zustand persist.

Старый формат сеанса не поддерживается по решению пользователя: после обновления
может понадобиться повторный вход. Рабочая БД не сбрасывалась.
