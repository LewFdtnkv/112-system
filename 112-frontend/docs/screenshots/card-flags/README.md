# Отметки карточки

- `arm-flags-desktop.png`, `arm-flags-mobile.png` — кликабельные отметки в АРМ,
  выделение выбранного значения. «Пострадавшие» — только кнопка, без числа
  и дополнительной модалки; оранжевые кнопки сохраняют оранжевую рамку при выборе.
- `arm-silent-call.png` — молчаливый вызов без выдуманного адреса и типа.
- `teacher-reference-flags.png` — редактирование эталонного решения.
- `generation-flags.png` — фиксированные и случайные факты до обращения к модели.
- `generation-silent-call.png` — сброс несовместимых параметров молчаливого вызова.

Скриншоты получены через `e2e/card-flags.spec.ts` на ответах API-фикстуры,
не на рабочей БД. На снимке АРМ намеренно включены все пять кнопок для проверки
сохранения ошибочного черновика; это не пример правильного молчаливого вызова.
В backend полный цикл молчаливой карточки и оценка проверены отдельно на PostgreSQL
в `tests/test_card_flags.py`.

Логика и ограничения генерации описаны в backend `docs/CARD_FLAGS.md`.
LLM пишет текст по заранее сохранённым фактам; смысл текста требует проверки
преподавателем. Молчаливый вызов создаётся шаблоном в том же воркере.
