# Фотографии пользователей

Проверка 26.09.2026. Desktop/mobile в Firefox; student-mobile в Chromium.
Снимки на API-фикстурах: портрет нарисован в SVG специально для теста, остальные пользователи без фото, с HTTP 404 или повреждённым изображением. Во всех трёх случаях показывается стандартная иконка человека.

Проверено: общий кэш фотографии в шапке, таблице и профиле; обновление всех экземпляров после загрузки; отсутствие прежнего фото при открытии другого пользователя; кликабельность имени; отдельная вкладка по «Подробнее»; отсутствие горизонтального переполнения мобильной шапки. Playwright: e2e/user-photos.spec.ts.
