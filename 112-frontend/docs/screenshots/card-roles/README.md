# Разделение карточки по ролям

Создание, редактирование и просмотр используют одинаковые три раздела:

- **Общие данные**: название, общая инструкция и заполненные поля происшествия.
  Для 112 это эталонное решение, для ДДС — входящая карточка.
- **Оператор 112**: сообщение заявителя, на основе которого ученик заполняет поля.
  При включённой подготовке ДДС его можно оставить пустым.
- **Оператор ДДС**: профиль службы, исходная история бригад, новые сообщения,
  учебные цели и обязательный звонок при новом назначении.

Навигация сверху перемещает к разделам, не скрывая поля от проверки формы.
При переходе из просмотра в редактирование форма открывается с начала.
Просмотр показывает исходную историю отдельно от новых сообщений и учебных целей;
неподготовленная для ДДС карточка имеет явное пояснение.

Снимки 27.09.2026: `create-*`, `edit-*`, `view-*`, desktop1440/mobile390.
Браузер использует API-фикстуры; проверены сохранение данных, отсутствие дублирования
сообщений, видимость разделов, обязательность условия 112 и ошибки формы.
Итоговые снимки просмотрены вручную. Рабочий АРМ и контракт backend не менялись.
