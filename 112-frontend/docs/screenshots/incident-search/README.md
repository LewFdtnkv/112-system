# Поиск происшествия с одного символа — 26.09.2026

Справочник версии карточки загружается один раз в TanStack Query. При необходимости
API читается несколькими страницами по 100 записей. Фильтрация по названию,
короткому названию и коду происходит сразу на клиенте, без запроса на каждый ввод.
Регистр и е/ё не различаются; пустой ввод показывает до 11 популярных типов.
Технические коды остаются скрыты в списке. Указания минимальной длины убраны из
поля и сопровождения. При открытии список прокручивается в видимую рабочую область.

Проверено в Docker: build, lint/FSD; пять сценариев Playwright Chromium
(новый поиск и четыре сценария сопровождения), новый поиск в Firefox.
Каталог фикстуры содержит 102 записи: проверены обе страницы, поиск «п» и «еЛ»,
буквальный знак %, очистка/пробелы, популярные типы, выбор и сохранение карточки.
После загрузки каталога новые поисковые запросы не выполняются. На узком экране
весь список расположен выше footer, внешний диалог не прокручивается.

Итоговые снимки Chromium/Firefox на широком и узком экране просмотрены вручную.
Браузер использует API-фикстуры; пагинация, доступ владельца, ограничение версии
каталога и новые подсказки отдельно проверены backend-тестами на временной БД.
