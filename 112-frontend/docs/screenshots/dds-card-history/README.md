# История бригад в карточке ДДС

Снято Playwright на API-фикстурах после завершения анимаций, 27.09.2026.
Интеграционные команды, снимки, источники аудита и оценка отдельно проверены backend
тестами на PostgreSQL. Эти изображения не являются скриншотами рабочей БД.

- `editor.png`, `editor-message.png` — настройка исходной истории и новой работы
  преподавателем в карточке библиотеки.
- `arm-1440.png`, `arm-390.png` — исходные записи и отдельное сообщение по выбранной
  бригаде; после ввода «Прибытие» тест проверяет новую запись и неизменность службы.
- `unassigned.png` — сообщение доступно и до назначения бригады.

Синий журнал, плитки, карандаш бригады и серая выбранная служба сохранены по образцу
целевой системы. Светлый блок сообщений — учебное дополнение, не запись статуса.
Итоговые изображения просмотрены вручную.
