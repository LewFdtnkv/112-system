# Форматы обращений

Настройки генератора: СМС без сведений о заявителе, описательный адрес без номера
дома, блокировка несовместимых параметров. Desktop и mobile лично просмотрены.
Проверка на API-фикстурах: `e2e/generation-message-formats.spec.ts`.
Сохранение через очередь и отсутствие оценки неизвестных сведений проверены
отдельно через FastAPI/PostgreSQL. Основной АРМ не изменялся.
