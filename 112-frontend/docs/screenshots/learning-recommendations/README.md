# Рекомендации по дальнейшему обучению

`desktop.png` и `mobile.png` — кабинет ученика с сообщением учебного помощника,
основанием рекомендации, переходом в назначенное занятие и обратной связью.
Снимки создаёт `e2e/learning-recommendations.spec.ts` на API-фикстурах.
Проверяются отзыв, повтор после ошибки, отметка прочтения и отсутствие рекомендаций
внутри АРМ. Реальные расчёты и очередь отдельно проверяются backend-тестами.
