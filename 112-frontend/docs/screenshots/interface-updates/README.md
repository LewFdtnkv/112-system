# Обновление интерфейса — 26.09.2026

Итоговые экраны Firefox просмотрены вручную; сценарии также проверены в Chromium.

- `login.png`: показ и скрытие пароля, Enter отправляет форму.
- `profile*.png`: собственные ФИО и фотография, без почты; аналогичные поля доступны администратору.
- `scenarios*.png`: длинные названия и фильтры без обрезания.
- `map-suggestions.png`: варианты адреса появляются во время ввода.
- `generation-address.png`: подтверждённый адрес с домом, корпусом, строением и координатами в генераторе.
- `telephone*.png`: длинный контакт и номера телефонов на широком и узком экране.

Браузерные проверки используют API-фикстуры и имитацию SDK карты. Реальная служба адресных подсказок на локальном API отдельно вернула варианты для запроса «Москва, Тверская». Сохранение профиля, права доступа и прохождение адреса через очередь генерации проверены backend-тестами на отдельной PostgreSQL. Реальная LLM для этих изменений не вызывалась.

Проверки: backend pre-commit и 421 pytest; frontend build, lint, FSD и 147 Vitest. Пройдены новые сценарии и регрессии в Chromium и Firefox.
