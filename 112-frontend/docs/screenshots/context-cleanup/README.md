# Проверка упрощения редакторов — 22.09.2026

- `operator.png`: Chromium, тестовые ответы API, открытие и повторное открытие
  карточки 112, затем сохранение/сдача в браузерном regression workflow.
- `dds.png`: Chromium, реальный API и завершённое демонстрационное занятие.
  Выбор службы, бригады, открытие истории, сворачивание всех панелей и закрытие
  работают через DDSWorkspaceContext. Рабочие ответы и статусы не менялись.

Оба снимка лично просмотрены, анимации отключены при захвате. Внешний вид АРМ
сохранён. Node, проверки и браузеры запускались в Docker.

Проверки: production build, ESLint/FSD, 113 Vitest и 6 Playwright.
16 тестов удалённых прототипных модулей удалены вместе с ними; добавлены 3
регрессии: сохранение после ошибки, блокировка повторной отправки, изоляция двух
карточек и контекста в MUI portal. Последняя обнаружила одинаковые id заголовков;
они заменены useId. Черновик и выбранные службы одной карточки не затрагивают другую.

Рабочего кода в src (без тестов) стало на 728 строк меньше с учётом новых контекстов.
Это сумма упрощения текущего редактора и удаления его неиспользуемых прототипных
веток/старого виджета карты, а не только эффект подключения библиотеки.
