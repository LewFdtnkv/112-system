# Карта и перевод: проверка интеграции

Снимки Playwright с API-фикстурами и имитацией JavaScript SDK Яндекс.Карт.
На карте намеренно нет реальных тайлов; снимки показывают только оболочку,
результат выбора адреса и форму перевода. Реальные ключи провайдеров не использовались.
Desktop/mobile снимки просмотрены; основной АРМ сопоставлен с image28 из КАРТОЧКА 112.docx.
