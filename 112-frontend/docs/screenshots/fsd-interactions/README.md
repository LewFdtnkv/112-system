# FSD и состояния элементов — 21.09.2026

Снимки Chromium в Docker на управляемых тестовых ответах API. Рабочая БД не
используется. Лично проверены после декомпозиции: сохранение компоновки АРМ,
читаемость таблицы/редактора, отсутствие горизонтального скролла страницы.

`e2e/interactions.spec.ts` проверяет всю строку, вложенную кнопку, Enter,
hover/active/focus-visible, сохранение адреса, выделение текста в поле и
`prefers-reduced-motion`. `e2e/arm-layout.spec.ts` — АРМ на 1920/1366/390 px.
