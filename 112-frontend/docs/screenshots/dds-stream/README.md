# Поток ДДС

Скриншоты Chromium на изолированных ответах API: журнал двух поступивших карточек,
просмотр второй при незавершённой первой, редактор отдельных интервалов поступления.
Получены e2e/dds-stream.spec.ts. Серверная выдача/реакция и права дополнительно
проверяются настоящим FastAPI/PostgreSQL в backend tests/test_dds_delivery.py.

Карточка сопоставлена со скриншотами 7/10 из «СКРИНШОТ ДДСГСИ.docx».
Область учебных указаний/переключения сверху относится к тренажёру;
нижние плитки служб/бригад и основная компоновка АРМ сохранены.
На изображениях телефония выключена: они не подтверждают SIP-медиасоединение.
