# Упрощение интерфейса — 27.09.2026

Снимки Playwright на API-фикстурах, без изменения рабочей БД.

- `table-*`, `detail-*`: список и подробности ИИ-задачи. UUID и диагностические параметры скрыты в раскрываемом разделе.
- `catalog-*`: службы без UUID, импорт ЕКП файлом, ширина полей на компьютере и телефоне.
- `assessment-*`: результат занятия для преподавателя и ученика, просмотр АРМ. Убраны версия модели/промпта и технические формулировки процесса.

Проверены фильтры/пагинация/обновление ИИ-задач, доступ к диагностике и безопасный вывод JSON; редактирование службы и импорт файла; профиль и история пользователя; генерация ДДС; просмотр оценивания. Все снимки лично просмотрены.
