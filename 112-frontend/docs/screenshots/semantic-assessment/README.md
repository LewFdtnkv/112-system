# Смысловое оценивание

- `teacher.png`: разбор карточки преподавателем, цитаты, спорный критерий и отдельная история прокторинга.
- `student.png`: итог ученика и рекомендации.

`e2e/semantic-assessment.spec.ts`, это не ответы живой модели. Снимки лично просмотрены.
АРМ сопоставлен со скриншотом из «СКРИНШОТ КАРТОЧКИ 112ГСИ.docx».
Реальная работа API/БД проверяется backend-тестами, качество модели — отдельными прогонами
в `112-backend/docs/SEMANTIC_ASSESSMENT_EVALUATION.md`.
