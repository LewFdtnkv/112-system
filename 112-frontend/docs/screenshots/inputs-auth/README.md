# Поля и отправка входа

Убраны общие hover/active-заливки и дополнительный outline с полей, осталась
собственная тонкая рамка/линия. Текст можно выделять и копировать.

- [Вход, Firefox](login-firefox.png)
- [Поиск карточки в фокусе, Firefox](cards-firefox.png)
- [Вход, Chromium](login-chromium.png)
- [Поиск карточки в фокусе, Chromium](cards-chromium.png)

Браузерная проверка в Docker (Linux): три последовательных входа через копирование
логина, вставку в пароль, дописывание `-123` и Enter в каждом браузере. Отдельно
проверены Enter из логина, валидация пустой формы и отсутствие заливки/outline.
Реальный API использован только для входа/выхода и чтения; учебные данные не менялись.
Firefox на macOS непосредственно не запускался.

Регрессия сохранена в `e2e/auth.spec.ts`; тесты формы также проверяют блокировку
повторной отправки и подтверждение ввода IME.
