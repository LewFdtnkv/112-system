# Занятия: личный лимит и выход — 26.09.2026

Итоговые снимки Firefox просмотрены вручную. Те же четыре сценария прошли в Chromium.

- `dashboard-active*.png`: выполняемые и доступные занятия отдельно; заметные роли112/ДДС, широкий и узкий экран.
- `timed-start.png`, `unlimited-start.png`: правила начала/продолжения.
- `timed-card.png`, `unlimited-card.png`: выход внутри учебной панели, общий остаток времени при лимите.
- `teacher-timing.png`: преподаватель задаёт минуты всего занятия и окно доступности.

Браузерные сценарии используют API-фикстуры. Проверены отдельный старт занятия и открытие первой карточки, сохранение свежего черновика до выхода, продолжение, два раздела кабинета и перевод25мин в1500с. Дополнительно прошли два сценария асинхронного поступления ДДС в обоих браузерах. Проверки backend на отдельной PostgreSQL подтверждают личные сроки, независимость учеников, паузы, сохранение расписания ДДС, автоматическую оценку непройденных карточек и ручной пересмотр. Полный backend:427тестов; frontend:149Vitest, build/lint/FSD.
