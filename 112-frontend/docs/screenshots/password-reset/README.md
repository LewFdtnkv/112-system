# Сброс пароля администратором

«Пользователи» → учётная запись → «Сбросить пароль». Администратор вводит
временный пароль (12–128 символов) и подтверждение. Ошибки длины, несовпадение
и ошибки API выделяют соответствующие поля. Пароль после отправки не показывается.

Успешный сброс завершает все сеансы пользователя. При следующем входе обязательна
замена временного пароля отличающимся личным. До замены сервер запрещает прикладные
операции. При сбросе собственного пароля администратор возвращается на страницу
входа. Роль и активность аккаунта сохраняются, история содержит автора сброса.

Снимки и браузерные проверки используют API-фикстуры; настоящие пароли стенда
не изменяются. Серверный процесс проверяется отдельно на тестовой PostgreSQL.
