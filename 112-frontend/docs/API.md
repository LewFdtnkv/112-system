# API и интеграции

Приложение обращается к FastAPI с префиксом `/api/v1`. Точные запросы и схемы доступны в Swagger бэкенда на `/docs`. Подмена ответов используется только в тестах.

## Запросы и ошибки

HTTP-функции находятся в `entities/*/api`, типы — в `types`, query options и хуки — в `model`. Общий клиент `shared/api/backendApi` добавляет токен и выполняет обновление сессии. TanStack Query хранит ответы, статусы загрузки и ошибок.

| Сущность            | Ответственность                                 |
| ------------------- | ----------------------------------------------- |
| `entities/user`     | Сессия, пользователи, фотографии и группы       |
| `entities/catalog`  | ЕКП, службы, профили и бригады                  |
| `entities/training` | Карточки, сценарии, занятия, сообщения и оценки |

Списки используют компактные представления `/views/*`. Детальный ответ загружается при открытии сущности. Не добавляйте отдельный запрос для каждой строки, если нужные поля уже есть в представлении.

Ошибки API содержат пользовательский `message` и `field_errors` с `path`, `message`, `code`. Свяжите их с полями формы, раскройте скрытый раздел и прокрутите к первой ошибке. Диагностические исключения не показывайте как пользовательский текст.

Записи передают ревизию. При конфликте сохраняйте ввод и предлагайте явно загрузить актуальную версию. Автоматический повтор со свежей ревизией может затереть чужие изменения.

## Авторизация

Вход — по логину и паролю. У аккаунта одна неизменяемая роль: ученик, преподаватель или администратор. После создания или сброса пароля доступна только обязательная смена пароля и выход.

| Запрос                       | Назначение         |
| ---------------------------- | ------------------ |
| `POST /auth/login`           | Вход               |
| `GET /users/me`              | Профиль и права    |
| `POST /auth/refresh`         | Обновление токенов |
| `POST /auth/change-password` | Смена пароля       |
| `POST /auth/logout`          | Выход              |

Zustand persist сохраняет только токены в sessionStorage. Профиль и права восстанавливаются с сервера. При выходе и смене пользователя Query-кэш очищается.

После 401 клиент один раз обновляет токены; параллельные запросы ждут общий refresh. Его 401 завершает сессию. Сетевая ошибка или 5xx показывают возможность повтора, а не сообщение о неверном пароле. Проверка поколения сессии не позволяет старому ответу восстановить уже закрытый аккаунт.

После обновления сборки устаревшая вкладка может ссылаться на удалённый файл JavaScript. Механизм восстановления предлагает перезагрузку и не должен создавать бесконечный цикл. Проверка этого случая находится в `e2e/asset-recovery.spec.ts`.

## Карта, адресный поиск и перевод

Карта использует JavaScript API Яндекс.Карт 2.1. Для локальной разработки задайте `VITE_YANDEX_MAPS_API_KEY` в `.env`. Ключ публичный: ограничьте его доменами приложения. Runtime-конфигурация `public/map-config.js` имеет приоритет:

```js
window.SYSTEM112_MAP_CONFIG = { apiKey: "ключ JavaScript API" };
```

В контейнере Nginx файл создаётся при старте из `SYSTEM112_MAPS_API_KEY` либо `VITE_YANDEX_MAPS_API_KEY`. Секретные ключи DaData и переводчика в frontend не помещаются.

Поиск и обратное геокодирование выполняются через `/addresses/suggest` и `/addresses/reverse`, перевод — через `/translations/translate`. Результат поиска применяется к черновику только после подтверждения. Без карты адрес можно заполнить вручную. Полноценный режим локальных карт не реализован.

## Телефония и записи

Браузерный телефон использует SIP.js/WebRTC. Backend выдаёт настройки закреплённой станции, Asterisk передаёт аудио. WebSocket `/sip-ws` должен поддерживать Upgrade. На удалённом стенде для микрофона нужен HTTPS с доверенным сертификатом; локально подходит `localhost`.

Успешный звонок определяется серверными событиями, а не нажатием кнопки. Для ДДС интерфейс показывает руководителя назначенной бригады и состояние подтверждения. При сетевом сбое не выставляйте успех на клиенте.

Записи загружаются или создаются из текста в редакторе карточки. До готовности озвучки её нельзя добавить. После закрытия диалога подготовка продолжается, запись доступна в библиотеке.
